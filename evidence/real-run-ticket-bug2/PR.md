# Done filter shows incomplete todos instead of completed ones

## Summary
Fixes a bug where selecting the **Done** filter displayed incomplete (active) todos instead of completed ones.

## Root Cause
In `app/public/app.js`, `visibleTodos()` had a negated predicate for the `'done'` filter (`todos.filter(t => !t.done)`), which duplicated the `'active'` filter logic.

## Fix
Updated the `'done'` filter branch in `visibleTodos()` to return `todos.filter(t => t.done)`.

## Verification
Verified via automated UI test recording: added three tasks (`Buy milk`, `Walk dog`, `Pay rent`), marked `Buy milk` as completed, switched to the **Done** tab, and confirmed that only `Buy milk` is rendered.
