# Long todo titles push the delete button off-screen due to nowrap and overflow hidden

## Context
On narrow/mobile viewports, adding a todo item with a long title caused the text to stay on a single line and expand beyond the `<li>` container. Because the list item has `overflow: hidden`, the sibling delete (`×`) button was pushed past the right edge and clipped, making it impossible for users to delete long tasks.

## Root Cause
In `app/public/index.html`, `.title` was styled with `flex: 1; white-space: nowrap;` inside a flex container (`li { display: flex; overflow: hidden; }`). Without allowing text wrapping or setting `min-width: 0`, the flex item could not shrink below its single-line content width, forcing the `.del` button outside the visible bounds of the row.

## Fix
Replaced `white-space: nowrap` on `.title` with `min-width: 0; overflow-wrap: anywhere;` so long titles can shrink and wrap across multiple lines inside the flex row while keeping the checkbox and delete button visible.

## Verification
Verified via an automated Playwright test running at a mobile viewport size:
1. Added a short task (`Buy milk`) and a long task (`Call the landlord about the broken heating in the upstairs bedroom before Friday`).
2. Confirmed the long task wraps onto multiple lines and its `×` delete button remains visible within the card.
3. Clicked the delete buttons for both tasks and verified the list returns to the empty state (`Nothing here.`).
